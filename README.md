# Our Love Sanctuary

Website statis (HTML, CSS, JS murni). Tidak perlu build.

## Hosting di GitHub Pages
1. Buat repository baru di GitHub, lalu upload SEMUA isi folder ini (index.html harus ada di root).
2. Buka Settings -> Pages.
3. Source: "Deploy from a branch", Branch: main, Folder: / (root). Klik Save.
4. Tunggu 1-2 menit. Situs aktif di https://USERNAME.github.io/NAMA-REPO/

## Mengubah isi
Semua teks, foto, dan lagu ada di bagian DATA paling atas file js/main.js.
- START_DATE  : tanggal mulai hitung mundur
- JOURNEY / LETTERS / MEMORIES : isi timeline, surat, galeri
- TRACKS      : isi "src" dengan file mp3 (taruh di assets/audio/) supaya lagu benar-benar terputar
Foto ada di assets/img/. Ganti dengan foto asli beresolusi tinggi (nama file sama) agar lebih tajam.
